# 🦍 Gorilla Camera v1.0.0
Created by Howell

A smooth, cinematic third-person camera mod for Gorilla Tag designed to help you record high-quality YouTube videos without headset shake!

## 🎥 Features
* **Cinematic Smooth Follow:** Automatically tracks your player smoothly.
* **Built-in 3D Model:** Spawns a physical black and neon-green camera body in the game world so others can see it.
* **OBS Optimized:** Outputs the camera angle directly to your PC monitor stream window.

## ⌨️ Controls
* Press **C** on your computer keyboard to turn the Gorilla Camera on or off.

## 📥 Installation
1. Download the `GorillaCamera.dll`.
2. Drop the file into your game's directory: `Gorilla Tag/BepInEx/plugins/`.
3. Launch the game via Steam VR and press C to start recording!
